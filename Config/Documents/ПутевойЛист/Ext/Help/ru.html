Документ «Доставочный лист»

 

Документ оформляет сборное перемещение по реализациям и выводит на печать пакет документов.

 

1. Заполнение таблицы

Подменю "Заполнить"

 

Кнопка "Заполнить за день" выбирает все заказы за день (ориентируется на дату документа + торговый представитель + склад/склад-промо) заполняет табличную часть заказами. Выбираются только те заказы, которые ещё не попали ни в какой другой доставочный лист.

Кнопка "Удалить строки без пометки" удаляет строки, в которых сняты флажки. Также, строки можно просто удалять сразу из таблицы.

Кнопка "Пересчитать вес" исправляет в старых документах неверно рассчитаный вес. В новых документах использовать ненужно.

Кнопка "Сбросить дату формирования пакета" ставит дату формирования всех реализаций в таблице на текущий момент (см. подробней в разделе печати).

 

Кнопка "Подбор" открывает окошко с заказами по выбранному в доставочном листе торговому представителю. Можно выбрать все заказы (нажать Ctrl+A),  можно выбрать несколько заказов зажав клавишу Shift или Ctrl. Заказы, которые уже включены в други доставочные листы автоматически пропускаются. 

 

2. Обработка таблицы

Подменю "Создание документов"

 

Кнопка "Создать общее перемещение, провести реализации" сначала заполняет самые ранние серии по дате поступления (для каждой номенклатура которая учитывается по сериям), после этого произойдет проверка на остатки по товарам. Если по какой-то продаже не хватит товара, откроется окошко с сообщением по исправлению отрицательных остатков.

Кнопка "Создать с\ф к реализациям" создат с\ф ко всем не упр. реализациям.

Кнопка "Разобрать доставочный лист" используется для разборки предварительного доставочного. Реализации остаются проведенными (товар резервируется под каждый документ на основном складе).

Кнопка "Распровести реализацию в тек. строке" используется для внесения исправлений в документ.

 

3. Исправление отрицательных остатков

 

Что делать с минусами:

При нажатии кнопки "Открыть" возле номенклатуры откроется отчет по остаткам, в котором можно посмотреть, почему остатков не хватает:

    - если отчет открылся пустой, значит указана неправильная номенклатура, по которой не было прихода - значит надо в реализации изменить номенклатуру на другую. Выключите флажок в строке.

    - если остатки по отчету есть, возможно произошла накладка с сериями. Выберите другую серию в реализации. Выключите флажок в строке.

    - если остатков действительно не хватило, то включаем флажок в строке (по умолчанию флажки везде включены)

   

По кнопке "Подтверить изменения" будут выполнены все действия по уменьшению\удалению строк. Исправляются только строчки, отмеченные флажками.

 

4. Печать пакета документов

После заполнения Доставочного листа проводим его. Без проведения печать пакета документов недоступна.

Слева указаны даты формирования пакетов.

Пример: Оператор собрал доставочный лист и сформировал перемещение, всем реализациям автоматически проставилось время этого события (13:50:43). Далее, оператор распечатал нужный набор доков, а потом добавил ещё пару заказов в этот же доставочный. У этой новой пары документов при проведении будет стоять уже новое время проведения (15:25:52). Чтобы при печати пакета ещё раз не выводить документы первой партии, нужно указать флажок только для второй части доставочного (только возле 15:25:52).

 

Таблица "Настройки печати" содержит формы, которые можно выводить в заданном количестве и порядке.

1. Печатаются формы с флажком "Начало пакета"

2. Печатаются все документы к заказам в доставочном. Флажок "Пропускать упр." ставится к распечаткам, которые не нужны для продажи с ВПД.

3. Печатаются формы с флажком "Конец пакета"

 

Последняя настройка печати сохраняется. В кнопке "Заполнить" есть несколько вариантов для теста.
